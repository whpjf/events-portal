# Практика 3. Разработка модулей ИС в соответствии с ТЗ

Сделано в папке `portal/`: фронтенд (шаблоны Jinja2 и CSS в `app/templates`, `app/static`), бекенд (FastAPI, маршруты в `app/routers`), база SQLite (SQLAlchemy и миграция Alembic).

## Что сделано

- Регистрация: логин (уникальный, 3-30 символов, латиница, цифры, `_`), пароль от 8 символов, почта и телефон по формату. Проверка в Pydantic-классе `RegisterForm`.
- Вход по логину и паролю, сессия в подписанной cookie.
- Создание заявки: помещение, способ оплаты, комментарий. На одно мероприятие одна заявка.
- «Мои заявки»: участник видит только свои.
- Панель администратора: все заявки в таблице и смена статуса (новая, назначено, завершено).
- ООП: модели `User`, `Event`, `Application`, сервисные классы `UserService`, `EventService`, `ApplicationService` в `app/services.py`.

Таблицы `statuses` и `reviews` из ER-диаграммы пока не создавал: статус лежит в заявке строкой, отзывы будут позже.
Пароли на этом этапе хранятся как есть, а поиск по названию собран строкой. Это исправлено в практике 4.
