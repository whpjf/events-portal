# Практика 8. Разработка дизайна с учётом современных тенденций

## Что сделано

- Взяла тенденции: минимализм (светлый фон, один акцентный цвет), карточный дизайн (афиша и заявки карточками), микро-взаимодействия (карточка приподнимается при наведении, кнопка меняет цвет и чуть опускается при нажатии, видимая рамка фокуса).
- Нарисовала макеты для телефона 390×844 и собрала их отдельными файлами в папке `mobile/`: `index.html` (афиша), `event.html` (мероприятие), `login.html` (вход), `apply.html` (заявка), `my.html` (мои заявки). Общие стили в `mobile.css`.
- Перенесла дизайн в сам портал: `portal/app/static/css/style.css`, шрифты Unbounded и Golos Text лежат локально, на телефоне меню прячется за кнопку «Меню» (`static/js/site.js`).
- Оптимизировала фото: из исходных JPEG (до 2,6 МБ) сделала WebP двух размеров, 640×480 для карточек и 1280×720 для страницы мероприятия. В карточках стоит `srcset`, телефон берёт маленький файл, ниже экрана картинки грузятся лениво.
- Проверила на телефоне: открыла сайт в режиме устройства 390×844 в Chrome.

## Вес картинок на афише

Измерял в Chrome (`performance.getEntriesByType('resource')`) на ширине 390, после прокрутки страницы до конца.

| | Картинок | Передано |
|---|---|---|
| До (исходные JPEG) | 8 | 9,3 МБ |
| После (WebP 640 px) | 8 | 0,63 МБ |

Все файлы на диске: было 9,5 МБ, стало 0,9 МБ (оба размера).
